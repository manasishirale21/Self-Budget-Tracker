# Self-Budget-Tracker

**BudgetTracker** is an Android application designed to help users track their daily expenses and manage their monthly budget effectively. It provides a simple and clean interface for recording expenses, visualizing spending, and keeping budget goals in check.

## Features

- Add, edit, and delete expenses.
- Categorize expenses (e.g., food, transportation, shopping).
- Visual overview of spending trends.
- Budget alerts if spending exceeds limits.
- Modern UI built with Jetpack Compose.

### Prerequisites

- Android Studio 
- Kotlin 1.5+
- Android SDK 21+
